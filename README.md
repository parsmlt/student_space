# Student Dashboard

A small student productivity website for keeping study tasks and deadlines in one place. Built as a beginner-friendly portfolio project with plain HTML, CSS, and JavaScript.

**Live site:** https://parsmlt.github.io/student_space/

## Features

- Add tasks with a subject and optional deadline
- Edit, complete, and delete tasks
- See counts for open tasks, tasks due this week, and completed tasks
- Switch between light and dark themes
- Keep tasks and the selected theme saved in the current browser
- Use the two pages on desktop or mobile

## Open the website

Open `index.html` in a web browser, then choose **Set up my study space** to visit the dashboard. No Python packages or build tools are needed.

## Project files

- `index.html` — welcome page
- `dashboard.html` — task dashboard
- `style.css` — layout and light/dark themes
- `app.js` — task editing and browser storage
- `theme.js` — theme switcher and saved preference

## Notes

Tasks are stored in browser storage on the current device. They do not sync to another device or account. This project does not use a server or database.
